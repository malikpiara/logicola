Informal fallacies are the most requested topic we'd never covered:
ad hominem, straw man, appeal to authority — the failure modes of
everyday argument, as opposed to the formal slips that syllogistic and
propositional logic catch.

Set R changes that. It's a full drill set on informal fallacies, and
it's also the first set built on a new question mode: instead of one
correct option among distractors, a question can ask you to identify
_every_ fallacy in play. Real arguments rarely fail in only one way, and
the drill now reflects that.

Set R is live now for everyone, no account needed —
[try it here](/informal/fallacies/quiz). As always, the set is aligned with the
corresponding chapter of Gensler's _Introduction to Logic_, so it slots
into a course the same way every other set does.

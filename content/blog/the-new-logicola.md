LogiCola 3 has a new face. Not a coat of paint — a redesign that started
from a question we kept running into: what should a logic drill _feel_
like when you're on your third run of the evening?

## A colour for every set

Each exercise set now has its own palette: a pale surface and a dark
chromatic ink, tuned as a pair. Syllogisms don't look like fallacies;
translations don't look like proofs. The palettes were derived in OKLCH
and checked against WCAG contrast requirements across every set — the
colours are calmer than they are loud, on purpose. You're here to think,
and the interface should hold the door open, not perform.

## Scored runs

The classic ten-question drill has grown into a scored run. Answer well
and the run builds; miss, and the bar flashes and takes the hit. The
scoring economies come from the original 2008 LogiCola — each set keeps
the weights it always had, so a score still means what your instructor
thinks it means.

## Pixels where it counts

The new interface borrows a bitmap grammar from the era LogiCola comes
from: straight edges stay ruler-straight, and only curves rasterise.
You'll see it in the icons, the badges, and the corners. It's a small
tribute to the software this project descends from.

## At home on your phone

Install LogiCola on your phone and it now behaves like it was born
there: system bars pick up the set's colour, the layout draws edge to
edge, and a round of fixes from a mobile audit smoothed out the details.
A practice session between classes is a first-class way to use LogiCola
now, not a compromise.

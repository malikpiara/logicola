A year ago LogiCola 3 worked. It just didn't know what it wanted to
be yet. Drag the lines below — left is August 2025, right is today.

## The front page

The old landing page led with a mascot and a promise. The new one
leads with the drills themselves: six topics, thirteen exercises, one
click from the fold.

## Starting an exercise

"Ready for a challenge?" was a chapter quiz on a brown card. Today's
start screen belongs to its set — each one wears its own colour
through the whole run — and it tells you what you're practising and
how the scoring works before you commit.

<div data-island="before-after" data-before="/blog/then-and-now/start-then.png" data-after="/blog/then-and-now/start-now.png" data-alt="The Set Q start screen" data-width="2498" data-height="1558"></div>

## Answering a question

The biggest change is the one you can't see in a screenshot: a wrong
answer used to just be wrong. Now it costs points, the bar flinches,
and the hint that appears is Gensler's own — the same explanation the
1990s program gave, ported from its original data files.

## Take one

This is the real drill, running in this page — same engine, same
scoring, same hints as the full exercise. Set Q asks what's wrong with
a definition; more than one answer can be right.

Checking platform support…

Selection — picking an option

Should feel like a tick, barely there. Fires on every option tap, so lightest wins.

Impact — Start Quiz

A commitment, so slightly weightier than selection — but still a thud, not a buzz.

Success — correct answer

Double pulse, mirroring iOS's native success pattern.

Error — miss

Heavier and flatter than success. It should register, not punish — the damage bar already does the scolding.

In sequence — the real quiz rhythm

Defaults played with quiz-like gaps: pick an option, beat, verdict.

iOS switch trick — for the iPhone test

These do nothing on Android. On an iPhone (Safari 17.4+, home-screen install included) each tap should give one Taptic tick via a hidden native switch. This is the part that needs your friend.

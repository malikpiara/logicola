Two questions here. Composition — tonight shipped one arrangement without alternatives, and it is centred, which is the model the QUESTION screen deliberately abandoned on 2026-08-22 (prompt top-anchored, answer group bottom-anchored, the 2008 window’s posture). The last screen of a run re-introducing it should be a decision, not an inheritance.

Button hierarchy — Malik, 2026-08-23: “it could make sense for the buttons to have different colors. Try the hard set is definitely more important than try again.” Agreed, and the treatments are more constrained than they look: a gem is clip-pathed, so it can paint no outline and no box-shadow — both are clipped away. Every border below is therefore a real two-layer gem, the same construction the focus band already uses (ringBand in lib/pixel.ts).

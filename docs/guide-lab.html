Guide content — findings & proposals

2026-08-21 · reviewed against the running product at 375×812.

Finding 1 — snaps ignore content (Set A)

Sets A/C/J's guides are one small table or a four-row notation group, but the sheet still offers 460px AND 97% snaps. At full, Set A is a heading, eight mono rows, and ~800px of empty surface — the exercise hidden for nothing. Proposal: size the expanded detent to content height and drop the full snap when content fits (HIG: detents exist to fit content, not the other way round). In vaul: compute the snap from the measured guide height.

Finding 2 — Set Q opens on the wrong half

The guide's DOM order is "What is a definition?" (two paragraphs) THEN "Ways a definition can be flawed". On mobile the columns stack, so a drilling user opens the guide onto prose and scrolls to reach the seven-flaw table — the thing the question actually asks about, whose numbers already mirror the option indexes. Directions to compare: table-first with the prose as an afterword, or table with the prose behind a disclosure. (Desktop's two-column layout can keep prose left — the reorder is a mobile-stacking concern.)

Finding 3 — Set R is a linear scan

Eighteen entries across ~5 screenfuls, prefixed by a 3-line intro, with no way to find one. A code-chip index was prototyped and KILLED by user testing (2026-08-21): nobody recalls fallacies by code — codes are the grading vocabulary, names are the recall vocabulary. Directions to compare, all with the intro cut:

  • Name index — a sticky jump-index of the eighteen short names (the option grid's own labels).
  • Families — the list grouped under four editorial subheads (Appeals · People and sides · Faulty structure · One-sided and off the point). The grouping is a lab proposal, not doctrine — the 2008 source doesn't group them.
  • Compact — no index; entries collapse to run-in lines so the whole list is ~2.5 screens and the scan itself gets cheap.

Round 3 — 2026-08-21 (Malik's briefs)

  • Set A, live letters: two directions — a letter legend above the abstract schema, or full substitution into the table. The pedagogy trade is real: the mapping from “logicians” to L is part of what the drill teaches, and substitution does that step for the student. The legend scaffolds without deleting; the live table optimises lookup at the cost of the abstraction. A thumb-and-classroom call.
  • Set Q, provenance: the shipped seven examples are verbatim Gensler §3.2 — a Routledge-relationship risk flagged by Malik. Directions: keep with a visible credit line, or replace with original examples (drafts in the lab, wording needs Malik's approval). NOTE: Set R's eighteen descriptions are near-verbatim from the same book — the provenance question is bigger than this sheet and needs its own pass.
  • Set R, the ∴ symbol: hard to read at 13.5px. Directions: styled (bigger, accent), spelled out as “Therefore”, or the five schema entries stacked as premise-over-conclusion lines — which also makes the inference SHAPE visible, arguably the most pedagogical of the three.
  • Dividers for the table sets: hairline (shipped) vs zebra vs cards vs open. Orthogonal to the direction dial, so any combination can be judged.

Type audit — 2026-08-22 (Butterick / Santa Maria pass)

  • Guide body 13.5px → 15px (why-lines 12.5 → 13, clauses 13 → 14, names 13.5 → 15, headings 15 → 16). Two reasons: the 15px web floor for read content on phones, and an internal inconsistency — the doctrine says the reference and the hints are one system, but the hint body is 15px and the guide wasn't.
  • .gwhy ink lifted 66% → 72% (small text at 66% mix needs a contrast check it would likely fail; 72% matches the reader-head tier). The port should gate it through lib/contrast.
  • text-wrap: balance on guide headings; tabular-nums on the code column. Caps tracking (0.10–0.12em on the mono micro-labels) already sits correctly in the 5–12% band — no change.
  • Standing exceptions kept: spaced em dashes are house style; the <u> on “must” is the 2008 source’s emphasis mark, restored by a dated decision — not an underline-for-emphasis violation to “fix”.

Not changed

The table/row anatomy itself (code chip · weighted name · ink gloss · hanging-numeral clauses) matches the hint hierarchy by design — that decision holds. The redesigns re-order and index; they don't restyle the rows.

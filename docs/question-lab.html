Question screen — two testing items, as directions

2026-08-22 · from user testing. Lenses: Norman (feedback, gulf of evaluation, mappings) and Refactoring UI (layout, spacing, hierarchy).

Item 1 — feedback above the question (one tester)

The shipped order — prompt → drill question → feedback → options — is the 2008 original's discourse order (decision 4, 2026-08-06): question, attempt, response. Norman's argument for it is mapping: feedback explains an OPTION, so it sits nearest the options. The tester's argument for "above the question" is also Norman: the eyebrow is the thing the hint is an answer TO ("what fallacy?" → "not that one, because…"), and on Set R the hint often sends you back to the PASSAGE — a hint adjacent to the passage shortens that re-read. Both are real; which wins depends on what the learner re-reads after a miss — the passage (argues above) or the options (argues between). That is a thumbs-and-eyes call, and one data point doesn't make it. Feel it on Set R especially.

Item 2 — reserve the question's and the answer's space

Two separate mechanisms produce the instability the tester felt:

  • Vertical centering (justify-center on the column): every prompt length lands the options at a different y, and a short prompt (Set C) floats over a block of dead space. Refactoring UI's rule — don't centre everything; left/top-anchor by default, centre only short heroes — applies literally. A top-anchored column with a reserved prompt region makes the options a fixed target across questions (Norman: predictable mappings; the eye learns where things are).
  • The mobile feedback exception (2026-08-19): on phones the slot sizes to its live content, so a miss shifts the options down. The rationale was honest — a reserved band is a third of a phone screen on Set R — but the tester asked for the stability anyway. Dial 3 restores the desktop contract on phones so the cost is feelable against the benefit. A middle path worth noting: reserve on list sets (hints are short) and stay live-sized on the grid set (where the cost is largest).

What to feel for

  • Set C, centered vs top+reserved: does the fixed layout read as calm or as a page that forgot to centre?
  • Set R, between vs above-the-question, after a miss: where do your eyes go next — passage or options?
  • Set R, reserved space: is the empty band on a first correct answer a price worth paying?
